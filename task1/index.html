    THE RECIPE

    What's actually happening?

    Seven concepts, one tiny coffee shop.

    01 / MEMORY

    Closures

    createOrderTracker() keeps the order count private. Its returned functions still access it after the outer function returns.

    02 / RIGHT NOW

    Call stack

    placeOrder → getPrice → addTax. Nested calls finish from the inside out. Follow their enter and return messages in the trace.

    03 / LATER

    Promises + async/await

    A Promise represents brewing. Its executor runs immediately. await pauses this function; the page stays responsive. Rejection goes to catch.

    04 / TAKING TURNS

    Event loop

    When the current task finishes and the stack is empty, queued microtasks run before the next task. Our Promise and queueMicrotask callbacks beat the zero-delay timer.
