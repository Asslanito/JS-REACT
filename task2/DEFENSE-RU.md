# Как объяснить React-проект

## Короткое описание

«Это моя персональная страница на React. Она рассказывает обо мне, показывает учебные проекты и содержит безопасные контакты. Страница адаптируется к телефону. Весь интерфейс разделён на компоненты, а фильтр проектов работает через React-состояние».

## Как приложение запускается

1. Браузер получает `index.html` с элементом `<div id="root">`.
2. `src/main.jsx` вызывает `createRoot` и рендерит `App`.
3. `App` собирает страницу из компонентов.
4. Vite преобразует JSX и собирает файлы для браузера. Node.js нужен для разработки и сборки; опубликованная страница работает в браузере.

## Компоненты

Компонент — функция, возвращающая JSX с описанием части интерфейса. Имена React-компонентов начинаются с большой буквы.

- `Header` — название и ссылки на разделы.
- `Hero` — имя, краткое описание, изображение.
- `About` — информация обо мне и карточки изучаемых технологий.
- `Projects` — список проектов и фильтр.
- `ProjectCard` — одна карточка; её содержание передаётся через props.
- `Contact` — публичный GitHub и «Planet Earth».
- `Footer` — нижняя часть страницы.
- `App` — объединяет эти части.

Требуется минимум 3 компонента; здесь 7 содержательных компонентов плюс `App`.

## JSX, props и state

JSX похож на HTML, но используется внутри JavaScript. Например, класс задаётся через `className`. Выражение JavaScript можно вставить в фигурные скобки.

В `ProjectCard({ project })` параметр `project` — prop. Родитель `Projects` передаёт объект, а карточка читает название, описание и ссылки. Компонент не изменяет полученный объект.

В `Projects` строка `const [filter, setFilter] = useState('All')` создаёт состояние. `filter` содержит выбранную категорию. Нажатие кнопки вызывает `setFilter(value)`, React повторно вызывает компонент и обновляет нужную часть интерфейса.

`projects.filter(...)` выбирает подходящие данные. `visibleProjects.map(...)` превращает их в компоненты карточек. `key={project.title}` помогает React сопоставлять элементы между обновлениями; названия в этом небольшом списке уникальны.

## Почему это SPA

Приложение содержит одну HTML-страницу. Навигация ведёт к секциям через якоря `#about`, `#projects`, `#contact`. При смене фильтра браузер не загружает новую страницу: React обновляет список. Для такого сайта отдельный роутер не нужен.

## CSS и доступность

Grid и Flexbox управляют расположением блоков. Media queries меняют число колонок и размеры на небольших экранах. Изображение имеет `alt`; кнопки фильтра используют `aria-pressed`; разделы имеют заголовки. Есть видимый фокус при использовании клавиатуры и ссылка Skip to content.

Сайт уважает `prefers-reduced-motion`. Контакты содержат только безопасные публичные данные.

## GitHub Pages

Исходный код хранится в GitHub. Workflow в `../.github/workflows/deploy.yml` запускается при push в `main`: `npm ci` устанавливает зависимости по lock-файлу, проверки ищут ошибки, `npm run build` создаёт `dist`. Общий скрипт scripts/build.mjs в корне объединяет сборки task1 и task2. GitHub Pages публикует их на одном сайте в разных подпапках.

В `vite.config.js` используется `base: './'`, чтобы ссылки на файлы работали и внутри пути репозитория. SVG подключён через `import.meta.env.BASE_URL`.

## Демонстрация на 2 минуты

1. Открой опубликованный сайт и покажи имя с изображением.
2. Перейди к About и контактам через меню.
3. Покажи, что нет телефона или домашнего адреса.
4. В Projects переключи All → JavaScript → React.
5. Открой `Projects.jsx` и объясни `useState`, `filter`, `map` и передачу props.
6. Открой `App.jsx` и перечисли компоненты.
7. Уменьши ширину браузера, чтобы показать мобильную версию.

## Вопросы, которые стоит уметь объяснить

**Чем prop отличается от state?** Prop приходит от родителя; state принадлежит компоненту и обновляется через setter.

**Почему нельзя просто присвоить новое значение переменной filter?** Обычное присваивание не сообщает React, что нужно заново отрисовать компонент. Для состояния нужен `setFilter`.

**Чем React отличается от первого задания?** В первом проекте DOM меняется вручную через `querySelector`, `createElement` и `textContent`. Здесь описывается интерфейс для текущего состояния, а обновление DOM выполняет React.

**Почему проект разбит на файлы?** Чтобы каждая часть имела понятную ответственность, а карточку можно было использовать повторно с другими props.

**Гарантирует ли красивый сайт максимальную оценку?** Оценку определяет преподаватель. Нужно проверить все материалы курса, сдать ссылки со скриншотом вовремя и понимать собственный код.
