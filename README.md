## Запуск

Требуется Node.js 24. В корне проекта:

```sh
npm ci
npm run setup
```

Первое задание:

```sh
npm run dev:task1
```

Второе задание:

```sh
npm run dev:task2
```

## Проверка и сборка

```sh
npm run check
npm run build
```

Оба задания публикуются на GitHub Pages через `.github/workflows/deploy.yml`.
